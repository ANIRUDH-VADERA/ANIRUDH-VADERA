## Selected Work

| Project / Initiative | What changed |
| --- | --- |
| **LATAM Ledger Expansion** | Expanded Walmart's financial ledger to **6 LATAM countries** and **200+ sources** with per-country isolation (Kafka, GCS, PostgreSQL), posting **10M transactions to SAP in 7 days**. |
| **Balanced SAP Document Splitting** | Split journals into balanced SAP documents under line-item and local-currency limits with exchange-rate conversion: **zero rejections across 100,000 documents**. |
| **Streaming Acknowledgements** | Re-architected the SAP acknowledgement flow from **hourly batch to sub-second** Kafka and Spark Streaming. |
| **Cloud Storage Archival Framework** | Reusable Python service on GCP Storage Transfer Service and AutoClass that archived **104 TB** and saves **$45,000 per year**. |
| **Audit Event Listener** | Scala/ZIO listener with Pub/Sub backpressure, idempotent dedup, and stuck-event recovery, cutting latency by **2-3 s/event**. |
| **PySpark-to-PostgreSQL Upsert** | Cut runtime from **3 hours to 13 minutes** with COPY into unlogged staging tables. |
| **Regression Testing Library** | Generic library covering 50+ business rules across **128+ repositories**, halving production failures. |
| **CodeSage AI** | LLM pipeline over **53,000 documents** (561 repositories, 1,386 incidents, 43 RCAs) with a NetworkX knowledge graph and ChromaDB. Finalist, Walmart FDF AI Hackathon. |
| **TwinAI** | Passive agent that turns IDE, terminal, browser, and LLM activity into a queryable digital twin of an engineer; now used by the entire team. |
